# Whisketch

A Catlyte notebook and whiteboard for handwritten notes, sketches and editable diagrams.

**Status:** planning and compatibility research. There is no application implementation yet.

Whisketch will work locally first, with Nextcloud storage and its Whiteboard web editor as the initial shared workspace. An alternative iCloud backend will support users of our Apple apps without Nextcloud. Native Apple clients should make writing and capture comfortable; PC access starts in the Nextcloud browser editor.
