# Whisketch 0.4.0 build 6

A simpler notebook-first workspace inspired by the quiet writing experience of TypeDraw, using original Catlyte visuals and the existing Excalidraw engine.

- Compact header with notebook navigation, title, focus and one actions menu.
- Paper-like canvas frame and a compact floating Write / Draw / Select / Erase palette with ink colour and Undo / Redo.
- Focus mode hides controls with a visible, accessible Show controls action.
- Library concentrates on search and notebook covers. Templates expand only when needed. The large illustration banner is removed from the everyday library view; Catlyte icon artwork is retained.
- Note settings gathers paper, covers, tags, appearance, favourites, checkpoints, import/export, backup, OCR and Nextcloud controls in one place.
- Advanced diagram mode restores the full editor toolset and shape libraries. Returning to notebook tools restores the compact palette.

Existing notes, editable scenes, imported images, paper backgrounds, local recovery and automatic Nextcloud syncing remain compatible. No cloud filename or sync-policy changes. This does not implement TypeDraw's pagination/page-curl animation, handwriting font generation, responsive Smart Marks, or iCloud; those are separate features.

References reviewed: https://apps.apple.com/us/app/typedraw/id6822194774 . Its publicly published screenshots inform the content-first direction; no TypeDraw fonts, artwork or source were copied.
