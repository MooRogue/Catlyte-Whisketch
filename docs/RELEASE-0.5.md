# Whisketch 0.5: notebooks that can be whiteboards

A notebook contains ordered, named pages. Every page mixes editable text, freehand ink, images and bound arrows/shapes. The same content can be viewed in the quieter notebook presentation or the wider whiteboard presentation. The shared toolbar includes writing, drawing, selection, erasing, arrows, shapes, image insertion and camera capture. Apple apps expose selected-image/ink OCR with a review step. Finger drawing and a Pencil-only toggle are available; actual Pencil ergonomics require device testing. Objects retain the drawing engine's selection, resize, rotation and binding behavior.

The existing MIT Excalidraw renderer remains an internal implementation detail. Whisketch now owns its `.whisketch` document envelope: schema version 1, metadata and ordered pages, each with content objects, image assets, paper and appearance. We promise neither Excalidraw interchange nor Nextcloud Whiteboard compatibility. Nextcloud is ordinary file storage, not the editor.

Before converting an old local library, its original data is preserved under `whisketch-before-notebooks-v2`. Older remote `.whiteboard` and `.excalidraw` files are never automatically rewritten or moved. Existing links are detached on upgrade and retained as legacy metadata; converted notebooks sync as new `.whisketch` files. Existing local notes and one-time imports retain editable ink/pressure/images. Export a library backup before upgrading important work. Page selection is local and does not create a cloud conflict.

Native Nextcloud credentials stay in Keychain. Web access adds a browser WebDAV adapter with credentials held in memory for the session, conditional create/update/rename, strong ETags, read-back verification, and the same conflict/checkpoint handling as the Apple apps. A browser deployment requires HTTPS and Nextcloud to permit its origin, methods and headers, including exposing ETag. An authenticated roundtrip against the owner's production server has not been tested. A web build is provided; no hosted site or Nextcloud server configuration is changed by this release.

Notebook PDF export in the Apple apps produces one PDF page per notebook page; PNG exports the selected page. PDF is an image rendering, not searchable/vector text. Notebooks with large photo collections may reach the existing 40 MB sync limit.

Not included yet: OCR search indexing, automatic handwriting-to-text while writing, photo perspective correction/cropping workflow, photo-to-editable diagram reconstruction, live collaboration, iCloud, native Windows packaging, or a deployed web service. Recognition preserves source ink/images and requires review. Real Pencil palm rejection, camera capture and the physical Duo layout need owner/device checks.
